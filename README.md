# Портфолио Степана Парфентьева

Статический сайт: HTML, CSS, JavaScript, шесть основных видеоработ, серия из семи анимированных поздравлений, два 3D-рендера и два сертификата.

Адрес после включения GitHub Pages: https://atlasqqw.github.io/portfolio/

## Публикация на GitHub Pages

1. Создать открытый (Public) репозиторий `portfolio` в аккаунте `ATLASQQW`.
2. Загрузить содержимое этой папки в корень репозитория. Файл `index.html` должен находиться сразу в корне, рядом с `styles.css`, `app.js` и папкой `assets`.
3. В репозитории открыть **Settings → Pages**.
4. В **Build and deployment → Source** выбрать **Deploy from a branch**.
5. Выбрать ветку **main**, папку **/(root)** и нажать **Save**.
6. Дождаться успешной публикации и открыть адрес сайта.

Файл `.nojekyll` отключает обработку Jekyll. Сборка и установка зависимостей не нужны.
Обычные файлы сайта и материалы находятся в открытом репозитории. Для этого портфолио используется бесплатный GitHub Pages с адресом github.io.

## Обновления

Изменения, отправленные в ветку `main`, публикуются автоматически. Картинки, видео и PDF находятся в `assets/`. Данные проектов и медиадиалогов — в `app.js`.
Поздравления расположены между After Effects и Blender: один плеер и список праздников. Разметка списка находится в `index.html`, переключение — в `holidays.js`, ролики и обложки — в `assets/holidays/`. На мобильных экранах список идёт под плеером. Без JavaScript ссылки списка открывают видео напрямую.
При переносе в другой аккаунт или переименовании репозитория обновить canonical, og:url и og:image в `index.html`.

## Локальный просмотр

Из этой папки можно запустить `python -m http.server 4173` и открыть http://localhost:4173/.
